# Rebranding: neues App-Icon und neue Screenshots, Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Roboter-Icon wird durch eine Kalender-Kachel aus einer SVG-Quelle ersetzt, alle Dateinamen werden neutral, und alle 14 README-Screenshots werden neu aufgenommen.

**Architecture:** `assets/app-icon.svg` ist die einzige Quelle. `scripts/app_icons.py` rendert sie mit `resvg-py` in jede Größe und schreibt mit Pillow `.png`/`.ico`/`.icns` und die PWA-Icons, dazu einen Stempel mit dem Hash der SVG. Die erzeugten Dateien werden eingecheckt; Build, CI und App brauchen nichts Neues. Danach werden App, Build, Installer und Doku auf `app-icon.*` umgestellt und die Screenshots mit dem neuen Icon aufgenommen.

**Tech Stack:** SVG, Python 3.12, `resvg-py==0.5.0` und `Pillow==13.0.0` (nur im Generator), pytest (Tests nur mit stdlib), Inno Setup, PyInstaller, Playwright/spectacle für die Screenshots.

**Spec:** `docs/superpowers/specs/2026-11-27-app-icon-design.md`

## Global Constraints

- Quelle `assets/app-icon.svg`, `viewBox="0 0 256 256"`, **keine** Elemente `filter`, `text`, `image`, `foreignObject`, `style`.
- Farben exakt: Kachel-Verlauf `#1b2a4a` → `#0e172b`, Mint `#04cd9f`, Cyan `#19ebec`, Blatt `#e6ecef`, Raster `#b6c2cc`, Zeiger `#ffffff`.
- Renderer nur im Generator: `resvg-py==0.5.0` mit `Pillow==13.0.0`, aufgerufen über `uv run --no-project --with resvg-py==0.5.0 --with Pillow==13.0.0 python scripts/app_icons.py`. Nicht in `requirements*.txt`, nicht in der CI, nicht in der Projekt-`.venv`.
- Tests nur mit stdlib: Pillow steht nicht in `requirements-test.txt`.
- Dateinamen: `assets/app-icon.svg`, `.png` (512 × 512), `.ico`, `.icns`, Stempel `assets/app-icon.svg.sha256`. PWA-Dateinamen bleiben (`pwa/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`). AppImage: `zeiterfassung.png` / `Icon=zeiterfassung`.
- `installer.iss`: `AppPublisher=Xveyn`. Unverändert bleiben `AppName`, `com.margenheld.zeiterfassung`, `LICENSE`.
- Commits, Kommentare, Issue, PR und CHANGELOG beschreiben die Änderung (neues Icon, neue Screenshots), **nicht ihren Anlass**.
- Kommentare nennen das Warum, keine Historie (`CLAUDE.md`, „Kommentare und Docstrings“).
- Historische Specs, Pläne, `CHANGELOG.md` und `CHANGELOG-archive.md` werden nicht angefasst.
- Commits bleiben lokal auf dem Branch `chore/neues-app-icon`. Push, Issue und PR erst nach Rückfrage beim Nutzer.

```python
def test_svg_is_renderer_neutral():
    root = ET.parse(SVG).getroot()
    assert root.get("viewBox") == "0 0 256 256"
    tags = {el.tag.rsplit("}", 1)[-1] for el in root.iter()}
    assert not tags & {"filter", "text", "image", "foreignObject", "style"}

def test_source_digest_ignores_line_endings():
    assert app_icons.source_digest("a\r\nb\r\n") == app_icons.source_digest("a\nb\n")

def test_generated_files_match_svg():
    """Nach jeder Änderung an der SVG `scripts/app_icons.py` ausführen."""
    stamp = STAMP.read_text(encoding="utf-8").strip()
    assert stamp == app_icons.source_digest(SVG.read_text(encoding="utf-8"))

def test_app_png_is_512_rgba():
    assert _png_info(ASSETS / "app-icon.png") == (512, 512, 8, 6)

def test_ico_carries_every_size():
    data = (ASSETS / "app-icon.ico").read_bytes()
    _, kind, count = struct.unpack("<HHH", data[:6])
    sizes = sorted((data[6 + 16 * i] or 256) for i in range(count))
    assert kind == 1
    assert sizes == [16, 20, 24, 32, 40, 48, 64, 128, 256]

def test_icns_carries_retina_sizes():
    data = (ASSETS / "app-icon.icns").read_bytes()
    assert data[:4] == b"icns"
    assert struct.unpack(">I", data[4:8])[0] == len(data)
    # Chunks ab Byte 8: 4 Byte Typ, 4 Byte Länge (inkl. Kopf)
    assert {"ic07", "ic08", "ic09", "ic10", "ic11", "ic12", "ic13", "ic14"} <= _icns_types(data)

def test_maskable_icon_is_full_bleed():
    assert _png_top_left_rgba(PWA / "icon-maskable-512.png")[3] == 255

@pytest.mark.parametrize("name", ["icon-192.png", "icon-512.png"])
def test_pwa_icons_keep_transparent_corners(name):
    assert _png_top_left_rgba(PWA / name)[3] == 0
```
